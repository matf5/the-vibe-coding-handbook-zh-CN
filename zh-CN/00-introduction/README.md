## 🎯 你将学到什么

完成这条学习路径后，你将掌握：

| 类别 | 获得的技能 |
|----------|-----------------|
| **🤖 AI 基础** | 理解 AI 模型、提示工程、AI 工具选择 |
| **💻 开发** | 在 AI 辅助下进行全栈开发（前端、后端、数据库） |
| **🛠️ 工具** | IDE、编辑器、AI 编程助手、调试工具 |
| **☁️ DevOps 与云** | CI/CD、容器化、云部署、监控 |
| **🏗️ 架构** | 系统设计、可扩展性模式、微服务 |
| **📱 移动与智能体** | 移动应用开发、AI 智能体、RAG 系统 |
| **💰 变现** | 自由职业、开源、产品构建、咨询 |
| **🎓 职业成长** | 面试准备、作品集构建、案例研究 |

## 👥 适合哪些人

### ✅ 非常适合：
- **初学者**：几乎没有编码经验，希望借助 AI 入门
- **传统开发者**：希望把 AI 融入工作流程
- **学生**：希望加速学习曲线
- **创业者**：希望快速构建 MVP
- **自由职业者**：希望提升生产力、承接更多项目
- **转行者**：正在转型进入技术行业

### ❌ 不适合：
- 指望完全自动化编码而不学习基础的人
- 不愿尝试和迭代 AI 输出的人
- 只想找复制粘贴方案而不求理解的人

### 学习建议

1. **按顺序开始**：按编号顺序学习，效果最佳
2. **每天练习**：每天至少花 1-2 小时动手编码
3. **构建项目**：通过迷你项目立即应用所学
4. **加入社区**：在讨论区与其他学习者交流
5. **定期复习**：经常重温速查表和提示词

## 📋 前置条件

### 必备（必须有）
- ✅ 基础电脑操作能力（文件管理、安装软件）
- ✅ 可访问 AI 工具的互联网连接
- ✅ 学习和尝试的意愿
- ✅ 已安装文本编辑器或 IDE（推荐 VS Code）

### 有帮助（最好有）
- 🌟 对编程概念的基本理解（变量、循环、函数）
- 🌟 熟悉命令行/终端
- 🌟 Git 基础（clone、commit、push）
- 🌟 HTML/CSS 基础

### 不需要
- ❌ 高等数学
- ❌ 计算机科学学位
- ❌ 多年编码经验
- ❌ 昂贵硬件（有云端选项）

## ✅ 入门检查清单

在深入学习内容之前，先完成以下配置步骤：

### 第 1 步：环境配置
- [ ] 安装 [VS Code](https://code.visualstudio.com/)
- [ ] 安装 Git（[Windows](https://git-scm.com/download/win)、[Mac](https://git-scm.com/download/mac)、[Linux](https://git-scm.com/download/linux)）
- [ ] 创建 GitHub 账号（如果还没有）
- [ ] Fork 本仓库到你的账号

### 第 2 步：AI 工具配置
- [ ] 注册 [Claude](https://claude.ai/)（推荐用于编码）
- [ ] 注册 [ChatGPT](https://chat.openai.com/)（备选）
- [ ] 安装 GitHub Copilot（可选，学生免费）
- [ ] 收藏 [Cursor IDE](https://cursor.sh/)（AI 原生编辑器）

### 第 3 步：学习配置
- [ ] 创建专门存放练习项目的文件夹
- [ ] 搭建笔记系统（Notion、Obsidian 或简单的 Markdown）
- [ ] 加入我们的社区 Discord/Slack（链接见 Resources）
- [ ] 每天安排 1-2 小时学习

### 第 4 步：心态准备
- [ ] 接受 AI 会犯错——验证是关键
- [ ] 承诺理解代码，而不仅仅是复制
- [ ] 拥抱迭代开发
- [ ] 准备好分享你的旅程（博客、Twitter 等）
