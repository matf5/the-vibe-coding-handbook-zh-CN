# 用 AI 进行面试准备

## 编程面试

### LeetCode 练习
```
Prompt: "Act as FAANG interviewer. Give me medium array problem.
After I solve, provide: correctness feedback, complexity analysis,
optimizations, similar problems."
```

### 模式识别
练习以下模式：
- 双指针
- 滑动窗口
- 二分查找
- DFS/BFS
- 动态规划
- 回溯

## 系统设计

### 经典问题
1. **设计 Twitter** - 信息流生成、规模
2. **设计 Uber** - 匹配、实时追踪
3. **设计 YouTube** - 视频存储、流媒体

### 框架：RESHADED
- 需求
- 估算
- 存储
- 高层设计
- 扩展性
- 热点
- 架构深入分析
- 细节

## 行为面试问题

### STAR 方法
- **S**ituation（情况）
- **T**ask（任务）
- **A**ction（行动）
- **R**esult（结果）

### 十大问题
1. 有挑战性的技术问题
2. 与队友的冲突
3. 失败与教训
4. 截止日期的优先级排序
5. 最自豪的项目
6. 与经理意见不一致
7. 需求变更
8. 指导他人的经历
9. 难打交道的利益相关者
10. 为什么选择这家公司？

## 模拟面试

### 模拟提示词
```
"Conduct mock interview:
1. 5 min: Introductions
2. 40 min: Coding problem
3. 10 min: Questions
Provide detailed feedback."
```

## 薪资谈判准备

### 调研
```
"Salary ranges for [role] at [level] in [location].
Include: base, equity, bonus, benefits."
```

### 话术
- 对初始 Offer 的回应
- 还价策略
- 利用多个 Offer
- 非薪资谈判
