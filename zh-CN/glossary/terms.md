# 氛围编程（Vibe Coding）术语表

## A

### AI-Assisted Development — AI 辅助开发
- **人们常说：**“让 AI 替你写代码”
- **实际含义：**一种协作式工作流：开发者描述意图、审查 AI 生成的代码、优化输出结果，同时保持对架构的掌控，并利用 AI 提升生产力
- **为什么重要：**在提速的同时，你始终掌握主导权

### Agent — 智能体
- **人们常说：**“一个能包办一切的自主 AI”
- **实际含义：**一种能够感知环境、做出决策并采取行动以达成目标的 AI 系统。实际上就是：LLM + 工具 + 执行循环
- **常用工具：**API 调用、文件操作、网络搜索、代码执行

### Autoregressive — 自回归
- **人们常说：**“AI 一次生成一个词”
- **实际含义：**一种模型，它以所有前文 token 为条件来预测下一个 token。所有主流代码生成模型（GPT、Claude 等）都是自回归模型
- **为什么重要：**理解这一点有助于你写出更好的提示词，并预判 AI 的行为

## B

### Backlog — 待办事项清单
- **人们常说：**“你的待办清单”
- **实际含义：**一份按优先级排列的清单，列出需要完成的功能、缺陷和任务。AI 可以帮你把大项拆解为可执行的步骤
- **最佳实践：**保持清单井然有序；需求越清晰、结构越明确，AI 的表现越好

### Build — 构建
- **人们常说：**“编译你的代码”
- **实际含义：**将源代码转换为可执行产物的过程。现代构建通常还包括代码检查、测试、打包和优化
- **AI 的作用：**AI 可以帮助调试构建错误和优化构建配置

## C

### Context Window — 上下文窗口
- **人们常说：**“AI 能记住多少内容”
- **实际含义：**一个 AI 模型在单次交互中最多能处理的 token 数量（单词、代码等）。上下文越大，AI 能考虑的信息就越多
- **典型规模：**8K–200K token，具体取决于模型

### Code Review — 代码审查
- **人们常说：**“检查代码能不能跑”
- **实际含义：**系统性地检查代码的正确性、安全性、性能和可维护性。AI 可以协助，但人的判断不可或缺
- **AI 的局限：**AI 可能会漏掉细微的缺陷或架构问题

### CI/CD — 持续集成/持续部署
- **人们常说：**“自动部署”
- **实际含义：**持续集成（每次变更都自动测试）+ 持续部署（自动发布到生产环境）。AI 可以帮助编写流水线和调试故障
- **常用工具：**GitHub Actions、GitLab CI、Jenkins、CircleCI

## D

### Debugging — 调试
- **人们常说：**“修 bug”
- **实际含义：**系统性地发现、定位和解决软件错误的过程。AI 可以给出修复建议，但理解根本原因还是你的工作
- **实用提示：**学会读错误信息；当你理解问题本身时，AI 对错误信息的解释会更有帮助

### Docker — Docker
- **人们常说：**“给应用用的容器”
- **实际含义：**一个用于在名为容器的隔离环境中开发、交付和运行应用的平台。它能保证开发环境与生产环境的一致性
- **AI 的作用：**AI 可以帮助编写 Dockerfile 和排查容器问题

### Deployment — 部署
- **人们常说：**“把你的应用上线”
- **实际含义：**让你的应用可供用户使用的过程，包括托管、配置、扩缩容和监控
- **常见平台：**Vercel、Netlify、AWS、GCP、Azure、Railway

## E

### Environment — 环境
- **人们常说：**“你的代码在哪里运行”
- **实际含义：**完整的运行配置，包括操作系统、依赖、配置和运行时。妥善的环境管理可以避免“在我的机器上能跑”的问题
- **最佳实践：**使用虚拟环境、容器或环境文件

### Editor — 编辑器
- **人们常说：**“你写代码的地方”
- **实际含义：**用于编写和编辑代码的软件。现代编辑器（VS Code、Cursor、Zed）直接集成了 AI 助手
- **AI 集成：**行内补全、聊天界面、重构工具

## F

### Frontend — 前端
- **人们常说：**“用户看到的部分”
- **实际含义：**在浏览器或应用中运行的客户端代码，包括 HTML、CSS、JavaScript 以及 React、Vue、Svelte 等框架
- **AI 的优势：**非常擅长生成 UI 组件、样式和响应式布局

### Framework — 框架
- **人们常说：**“一个用来构建应用的库”
- **实际含义：**一套结构化的基础，包含用于构建应用的既定模式和工具。它提供的约定可以加快开发速度
- **示例：**Next.js、FastAPI、Django、Express、Spring Boot

## G

### Git — Git
- **人们常说：**“版本控制”
- **实际含义：**一种分布式版本控制系统，用于跟踪源代码的变更。对协作和维护代码历史至关重要
- **AI 的作用：**AI 可以帮助编写提交信息、解释 diff 和解决合并冲突

### Generative AI — 生成式 AI
- **人们常说：**“能创造东西的 AI”
- **实际含义：**基于从训练数据中学到的模式生成新内容（文本、代码、图像）的 AI 系统。其工作原理是预测接下来会出现什么
- **局限：**可能会产生幻觉；务必核实输出结果

## H

### Hallucination — 幻觉
- **人们常说：**“AI 在胡编乱造”
- **实际含义：**AI 生成了听起来合理但不正确或凭空捏造的信息。常见于冷门 API、近期事件或具体事实
- **应对方法：**核实关键信息；用 AI 处理模式类问题，而不是事实类问题

### Hosting — 托管
- **人们常说：**“你的网站住在哪里”
- **实际含义：**为用户提供应用服务的基础设施。选择会影响性能、成本、可扩展性和维护工作量
- **可选方案：**静态托管（Vercel、Netlify）、VPS（DigitalOcean）、云服务（AWS、GCP）、PaaS（Railway、Render）

## I

### IDE — 集成开发环境
- **人们常说：**“加强版代码编辑器”
- **实际含义：**集成开发环境——集编辑器、调试器、构建工具等功能于一体。现代 IDE 集成了 AI 助手
- **常见选择：**VS Code、JetBrains 系列、Cursor、Zed

### Inference — 推理
- **人们常说：**“运行 AI 模型”
- **实际含义：**使用已训练好的 AI 模型生成预测或输出。与训练不同；通常更快、资源消耗更少
- **成本因素：**推理按 token 收费；优化提示词可以减少用量

## J

### JavaScript — JavaScript
- **人们常说：**“Web 的语言”
- **实际含义：**一种用途广泛的编程语言，可在浏览器和服务器（Node.js）中运行。在前端占据主导地位，在后端也在不断发展
- **AI 支持：**非常出色；大多数 AI 编程工具都经过了大量 JavaScript 训练

### JSON — JSON
- **人们常说：**“数据格式”
- **实际含义：**JavaScript 对象表示法（JavaScript Object Notation）——一种轻量级数据交换格式，人和机器都易于读写
- **AI 的优势：**AI 非常擅长生成和解析 JSON 结构

## K

### Knowledge Base — 知识库
- **人们常说：**“文档”
- **实际含义：**关于某个产品、系统或领域的集中式信息库。对入职和查阅至关重要
- **AI 的作用：**AI 可以帮助整理、搜索和更新文档

## L

### LLM — 大语言模型
- **人们常说：**“那个 AI”
- **实际含义：**大语言模型（Large Language Model）——一种在海量文本数据上训练的神经网络，用于理解和生成人类语言，为 AI 编程助手提供动力
- **常用模型：**GPT-4、Claude、Llama、Mistral

### Latency — 延迟
- **人们常说：**“响应有多快”
- **实际含义：**请求与响应之间的延迟。对用户体验至关重要；受网络、服务器和处理时间影响
- **对 AI 的影响：**AI 生成的代码应当考虑延迟因素

### Library — 库
- **人们常说：**“可复用的代码”
- **实际含义：**一组预先编写好的函数和类的集合，可在项目中使用。节省时间、减少错误
- **AI 的好处：**AI 了解常用库，可以推荐合适的库

## M

### Model — 模型
- **人们常说：**“AI 的大脑”
- **实际含义：**一种经过训练的神经网络，可以执行特定任务。不同的模型擅长不同的事情（代码、文本、图像）
- **如何选择：**根据任务、成本、速度和准确性需求来选择

### Middleware — 中间件
- **人们常说：**“请求与响应之间的代码”
- **实际含义：**在请求—响应周期中执行的函数，用于身份验证、日志记录、校验等
- **AI 的作用：**AI 可以生成常见的中间件模式

## N

### Node.js — Node.js
- **人们常说：**“跑在服务器上的 JavaScript”
- **实际含义：**一种在浏览器之外执行 JavaScript 的运行时环境，使全栈 JavaScript 开发成为可能
- **生态系统：**npm 拥有数百万个包；AI 可以帮你从中筛选

### Neural Network — 神经网络
- **人们常说：**“会学习的 AI”
- **实际含义：**一种受生物大脑启发的计算系统，由相互连接的节点（神经元）组成，用于处理信息
- **相关性：**了解基础知识有助于你更好地使用 AI 工具

## O

### Open Source — 开源
- **人们常说：**“免费软件”
- **实际含义：**源代码公开、任何人都可以查看、修改和改进的软件。由社区共同建设
- **与 AI 的关联：**许多 AI 工具都是开源的；参与贡献对所有人都有益

### Optimization — 优化
- **人们常说：**“让它更快”
- **实际含义：**提升代码性能、减少资源占用或提高效率。可以针对速度、内存、成本或能耗进行优化
- **AI 协助：**AI 可以给出优化建议，但优化前后都要实测

## P

### Prompt — 提示词
- **人们常说：**“你输入给 AI 的内容”
- **实际含义：**你提供给 AI 系统以获得期望输出的输入。提示词的质量直接影响回答的质量
- **关键技能：**提示工程是可以学习的；清晰度和上下文很重要

### Prompt Engineering — 提示工程
- **人们常说：**“跟 AI 好好说话”
- **实际含义：**设计输入以引发 AI 最优回应的技艺，包括提供上下文、示例、约束条件和明确目标
- **关键洞见：**把 AI 当作初级开发者对待——要具体，并提供示例

### Production — 生产环境
- **人们常说：**“真实的东西”
- **实际含义：**你的应用为真实用户服务的线上环境。要求可靠性、监控和快速的问题解决能力
- **AI 注意事项：**AI 生成的代码在投入生产之前要充分测试

### Python — Python
- **人们常说：**“简单的编程语言”
- **实际含义：**一种以可读性著称的高级解释型语言，在 AI/ML、数据科学、脚本和后端开发中占据主导地位
- **AI 的优势：**大多数 AI 编程工具都非常擅长 Python

## R

### Refactoring — 重构
- **人们常说：**“清理代码”
- **实际含义：**在不改变外部行为的前提下重组现有代码，提高可读性、可维护性和性能
- **AI 的强项：**非常擅长给出重构建议并执行重构

### Repository — 仓库
- **人们常说：**“你的项目文件夹”
- **实际含义：**存放代码的存储位置，通常由 Git 管理，包含代码、历史、分支和协作功能
- **最佳实践：**清晰的结构和文档有助于 AI 理解你的项目

### REST API — REST API
- **人们常说：**“Web 服务”
- **实际含义：**一种使用 HTTP 请求设计网络应用的架构风格，是服务之间通信的标准方式
- **AI 的能力：**AI 可以生成 API 端点和客户端代码

## S

### Stack — 技术栈
- **人们常说：**“你的技术选型”
- **实际含义：**构建应用所用技术的组合（前端、后端、数据库、基础设施）
- **常见技术栈：**MERN、LAMP、JAMstack、T3

### Security — 安全
- **人们常说：**“把黑客挡在门外”
- **实际含义：**保护系统、数据和用户免受威胁的实践与技术。必须从一开始就内置，而不是事后补加
- **AI 警告：**未经专家审查，绝不要信任 AI 处理安全关键代码

### SQL — SQL
- **人们常说：**“数据库语言”
- **实际含义：**结构化查询语言（Structured Query Language）——用于管理和查询关系型数据库。对数据驱动的应用至关重要
- **AI 的优势：**非常擅长编写和解释 SQL 查询

### Testing — 测试
- **人们常说：**“确保它能正常工作”
- **实际含义：**系统性地验证代码是否按预期运行，包括单元测试、集成测试、端到端测试
- **AI 的作用：**AI 可以生成测试用例，但测什么由你来定义

## T

### Token — 词元
- **人们常说：**“AI 的词”
- **实际含义：**AI 模型处理文本的基本单位，大约相当于 4 个字符或 0.75 个单词。模型可处理的 token 数量有限
- **成本影响：**token 越多，成本越高；要言简意赅

### TypeScript — TypeScript
- **人们常说：**“带类型的 JavaScript”
- **实际含义：**JavaScript 的超集，增加了静态类型。能在编译时而非运行时发现错误
- **AI 的好处：**类型注解有助于 AI 理解你的意图

## U

### UI/UX — 用户界面/用户体验
- **人们常说：**“它看起来和用起来的感觉”
- **实际含义：**用户界面（User Interface，视觉元素）+ 用户体验（User Experience，整体交互）。对用户接受度至关重要
- **AI 的优势：**非常擅长生成 UI 组件；用户体验则需要人的同理心

### Unit Test — 单元测试
- **人们常说：**“小测试”
- **实际含义：**验证单个函数或组件在隔离状态下是否正常工作的测试。快速且可靠
- **AI 的能力：**AI 非常擅长根据代码生成单元测试

## V

### Version Control — 版本控制
- **人们常说：**“跟踪变更”
- **实际含义：**记录文件随时间变化的系统。支持协作、回滚和试验
- **标准：**Git 是通用标准；要好好学习它

### Vibe Coding — 氛围编程
- **人们常说：**“AI 辅助开发”
- **实际含义：**一种方法论：开发者与 AI 协作，以更快速度设计、构建、调试和部署软件，同时保持质量
- **核心原则：**AI 放大人的能力；基础知识依然重要

## W

### Workflow — 工作流
- **人们常说：**“你的工作方式”
- **实际含义：**你完成任务时可重复的流程。好的工作流会在合适的阶段利用 AI
- **优化：**随着 AI 工具的发展，不断优化你的工作流

## Z

### Zero-Shot — 零样本
- **人们常说：**“不需要示例”
- **实际含义：**不提供示例就让 AI 执行任务，依赖模型的通用知识
- **何时使用：**用于常见任务；复杂或特定的需求请提供示例
